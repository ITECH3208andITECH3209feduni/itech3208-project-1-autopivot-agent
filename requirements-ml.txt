# AutoPivot — full dependencies, including the vision stack
#
# Installs the core requirements plus everything autopivot_backend.py needs:
#
#     pip install -r requirements-ml.txt
#     python autopivot_backend.py
#
# Several gigabytes. An NVIDIA CUDA GPU or Apple MPS GPU is useful, but the
# complete pipeline also works on CPU when no accelerator is available.
#
# ── torch and torchvision are NOT in this file, on purpose ────────────────────
#
# On Windows, `pip install torch` fetches the CPU-only build from PyPI. It
# installs without complaint, imports without complaint, and then reports
# torch.cuda.is_available() == False forever — the GPU is simply never used,
# and nothing in the error output points at the cause.
#
# The CUDA build lives on PyTorch's own index and has to be asked for by name:
#
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#
# setup.bat does this first, before installing this file. Because torch is
# already present by then, the packages below that depend on it — ultralytics,
# timm, kornia — resolve against the CUDA build rather than pulling the CPU one
# in behind your back.
#
# If you are setting up by hand, install torch that way first.

-r requirements.txt
