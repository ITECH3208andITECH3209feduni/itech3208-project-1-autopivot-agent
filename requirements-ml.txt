# ML / Vision
#
# torch and torchvision are deliberately NOT pinned and usually not installed
# here at all: a GPU host image ships a build matched to its CUDA driver, and
# replacing it with a generic wheel is how a working GPU stops being detected.
#
# transformers IS pinned, and has to be. It tracks torch's internal APIs
# closely — releases from 4.46 onward import DTensor from torch.distributed
# .tensor, which does not exist in the torch that most GPU images still ship.
# Unpinned, pip installs the newest release and the import fails at startup
# with no obvious connection to the version you actually have.
huggingface_hub
transformers>=4.40,<4.46
torch
torchvision
opencv-python-headless
ultralytics
numpy
kornia
